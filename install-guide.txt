## Init shadcn
- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - 
npx shadcn@latest init

1. after you install shadcn delete components/ui folder and move lib/utils.ts file to shared/utils/utils.ts and then in component.json replace below code:
  "aliases": {
    "components": "@/shared/components",
    "utils": "@/shared/utils",
    "ui": "@/shared/components/shadcn-ui",
    "lib": "@/shared/utils",
    "hooks": "@/hooks"
  },

  2. After this when you install any component from Shadcn then don't forget to add the correct path import { cn } from "@/shared/utils/utils";
  
  3. When you install calendar from shadcn then edit as below:
      // @ts-expect-error - 'table' is a valid key in react-day-picker's classNames but TypeScript types are outdated
      table: "w-full border-collapse",
